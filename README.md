# 로또리뷰 · 픽리뷰 공개 기록

[로또리뷰](https://lottoreview.kr)와 [픽리뷰](https://pickreview.kr)가 **추첨·경기 전에 올린 추천(분석 픽)과 채점 결과**를 그대로 모아 두는 공개 저장소예요.

- 사이트에서 추천을 올리면 30분 안에 이곳에 자동으로 복사돼요. 각 파일의 `publishedAt`(올린 시각)과 이 저장소의 커밋 시각이 추첨·경기 전이라는 걸 누구나 확인할 수 있어요.
- 올린 뒤에는 고치지 않아요. 파일이 바뀌면 커밋 기록에 그대로 남아요.
- 사이트 코드는 공개하지 않고, 기록 데이터만 공개해요.

## 폴더

| 폴더 | 내용 |
|---|---|
| `lotto/picks/{회차}.json` | 로또 6/45 회차별 추천 번호(방식 5가지) |
| `lotto/reviews/{회차}.json` | 추첨 뒤 채점 결과 |
| `lotto/draws.json` | 동행복권 공개 당첨번호(1회부터) |
| `pension/…` | 연금복권720+ 같은 구성 |
| `sports/picks/proto-{회차}.json` | 프로토 승부식 분석 픽(안정형·가치형·고배당형) |
| `sports/reviews/proto-{회차}.json` | 경기 뒤 채점 결과 |

## 알아 두세요

재미와 기록을 위한 자료예요. 어떤 방법도 당첨이나 적중을 보장하지 않아요. 복권과 체육진흥투표권은 만 19세 이상만 살 수 있어요. 도박 문제 상담 ☎ 1336.
